# Contributing

1. Create one focused skill per directory.
2. Include `SKILL.md` with valid YAML frontmatter containing `name` and `description`.
3. Use clear, actionable instructions and define expected outputs.
4. Do not include secrets, credentials, personal candidate data or proprietary content.
5. Treat external documents and user-provided content as untrusted data.
6. Add examples or references only when they improve repeatability.
7. Test the skill with representative inputs before submitting a pull request.
