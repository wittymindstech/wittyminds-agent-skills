# Docker and DevOps

## Practices
- Use minimal trusted base images.
- Pin dependencies and image versions.
- Use multi-stage builds where beneficial.
- Run as a non-root user.
- Keep secrets out of images and build logs.
- Add health checks where appropriate.
- Scan dependencies and images.
- Automate linting, tests and build validation.
- Promote immutable artifacts across environments.
- Use deployment approvals and rollback strategies.
- Monitor deployments and application health.

## Output
Return Dockerfile or pipeline design,
security checks, deployment stages, rollback and validation steps.
