# AWS Cost Optimization

## Objective
Reduce cloud spend while preserving required performance, reliability and security.

## Procedure
1. Gather workload, region, utilization and billing assumptions.
2. Identify major cost drivers.
3. Evaluate right-sizing and autoscaling.
4. Evaluate storage tiers, lifecycle and retention.
5. Evaluate data transfer and network architecture.
6. Evaluate managed service and serverless options.
7. For AI workloads, assess model choice, token volume, caching, batching and routing.
8. Compare options against performance and availability requirements.
9. Quantify savings only when pricing and usage data support the calculation.
10. Recommend monitoring and budgets.

## Rules
Do not promise savings without evidence.
Use current AWS pricing for estimates and state assumptions.
Do not optimize away required security or resilience.

## Output
Return cost drivers, opportunities, assumptions,
estimated impact where supportable, trade-offs and action plan.
