# API Design

## Objective
Create APIs that are predictable, secure and maintainable.

## Practices
- Define resources and operations clearly.
- Use appropriate HTTP methods and status codes.
- Define request and response schemas.
- Validate inputs and enforce authorization.
- Design consistent error responses.
- Support pagination, filtering and sorting where needed.
- Define idempotency for suitable operations.
- Plan versioning and backward compatibility.
- Apply rate limits and payload limits.
- Document APIs with OpenAPI.
- Add correlation IDs, logs and metrics.

## Output
Return endpoint list, schemas, status codes,
security requirements, versioning and test cases.
